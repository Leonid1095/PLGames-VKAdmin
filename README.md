# VKAdmin — AI-администратор для групп ВКонтакте

Полноценный бот-администратор с ИИ для управления сообществами VK. Автоматическая модерация, генерация контента, геймификация, аналитика и кросс-постинг в Telegram.

## Возможности

### Для участников
- **Геймификация** — XP за комментарии, лайки, репосты; уровни и достижения
- **Личный кабинет** — профиль с прогресс-баром, статистикой и бейджами
- **Лидерборд** — рейтинг топ-50 с фильтрами (XP, уровень, репутация)
- **Магазин** — VIP-статус и внутренняя валюта
- **Предложка** — пользователи предлагают посты, админ одобряет одним кликом

### Для администраторов
- **AI-контент** — генерация постов и статей из URL
- **Автопостинг** — парсинг RSS/VK/сайтов + ИИ-переписывание (только свежее, только при включённом автопостинге)
- **Умная модерация** — AI-анализ токсичности комментариев; удалить/забанить VK позволяет только личному ключу админа, поэтому бот присылает админу ссылку на нарушение (см. «Ограничения ключа сообщества»)
- **Контент-план** — визуальный календарь на 7 дней, планирование
- **Аналитика** — лайки, комментарии, просмотры, репосты последних постов (дашборд и Mini App), топ участников
- **Рассылка** — отправка сообщений всем участникам
- **Виджет** — таблица лидеров прямо на странице группы

### Интеграции
- **VK Mini App** — полноценное приложение внутри VK с навигацией
- **Telegram** — автоматический кросс-постинг в канал
- **OpenRouter / свой AI** — любой LLM-провайдер

## Архитектура

```
FastAPI (uvicorn) — веб-сервер
├── VK Callback API — приём событий от VK
├── Mini App — пользовательский интерфейс внутри VK
├── Dashboard — веб-панель администратора
├── Public API — REST API с авторизацией
└── APScheduler — фоновые задачи
    ├── Автопостинг (каждый час)
    ├── Публикация запланированных постов (каждые 5 мин)
    ├── Контент-задачи по cron
    ├── Аналитика (каждый час + сразу после старта)
    ├── Дайджест админу (раз в день после 10:00 МСК)
    └── Обновление виджета (каждый час)
```

**Multi-tenant** — один инстанс обслуживает множество групп. Каждая группа изолирована через `group_id`.

## Быстрый старт

### 1. Установка

```bash
git clone https://github.com/Leonid1095/PLGames-VKAdmin.git
cd PLGames-VKAdmin
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка

```bash
cp .env.example .env
# Заполните .env — минимально нужны:
# VK_APP_ID, VK_APP_SECRET, OPENROUTER_API_KEY, ENCRYPTION_KEY, JWT_SECRET
```

Генерация ключа шифрования:
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

### 3. Запуск

```bash
python main.py
# Сервер на http://localhost:8000
```

### 4. Подключение группы

1. Откройте `https://yourdomain.com/dashboard`
2. Введите пароль (= `DASHBOARD_PASSWORD` из `.env`)
3. Укажите ID группы и нажмите "Подключить"
4. Авторизуйте приложение в VK

## Как управлять ботом

Команд нет — бот понимает обычный язык. Админ пишет в ЛС сообщества:
«напиши пост про обновление», «как дела в группе?», «следи за RSS https://…»,
«позови меня, если спросят про оплату». Участникам бот отвечает как сотрудник
поддержки и зовёт живого админа, когда не уверен или об этом просят.

Тесты: `pip install -r requirements-dev.txt && python -m pytest`.

## Ограничения ключа сообщества VK

Бот работает от ключа сообщества. По схеме VK API (`access_token_type`) и живой
проверке (09.2026) часть методов ему недоступна — VK отвечает error 27
«method is unavailable with group auth»:

| Действие | Метод | Ключ сообщества | Как сделано |
|---|---|---|---|
| Статистика постов, чтение стены | `wall.get` | ❌ | сервисный ключ `VK_APP_SERVICE_KEY` |
| Удалить комментарий | `wall.deleteComment` | ❌ | уведомление админу со ссылкой |
| Бан / разбан | `groups.ban` / `groups.unban` | ❌ | уведомление / инструкция админу |
| Закрепить пост | `wall.pin` | ❌ | инструкция админу |
| Фото к постам | `photos.getWallUploadServer` | ❌ | посты уходят без картинок |
| Посты, ответы, ЛС | `wall.post`, `wall.createComment`, `messages.send` | ✅ | — |

Полное удаление/бан/фото требуют личного ключа администратора — это отдельное решение.

## Переменные окружения

| Переменная | Обязательно | Описание |
|-----------|------------|----------|
| `VK_APP_ID` | Да | ID приложения VK |
| `VK_APP_SECRET` | Да | Секрет приложения VK |
| `OPENROUTER_API_KEY` | Да | API-ключ AI-провайдера |
| `ENCRYPTION_KEY` | Да | Fernet-ключ для шифрования токенов |
| `JWT_SECRET` | Да | Подпись сессий Mini App (не пароль!) |
| `DASHBOARD_PASSWORD` | Да | Пароль входа в dashboard |
| `SESSION_SECRET` | Нет | Сид сессионной куки dashboard (по умолч. из `JWT_SECRET`) |
| `VK_APP_SERVICE_KEY` | Да | Сервисный ключ приложения — чтение стены (статистика постов, анализ группы) |
| `CALLBACK_REQUIRE_SECRET` | Нет | `true` — отбрасывать события групп без секрета |
| `PEXELS_API_KEY` | Нет | Поиск картинок к постам |
| `BASE_URL` | Да | Публичный URL сервера |
| `VK_MINIAPP_ID` | Нет | ID VK Mini App |
| `VK_MINIAPP_SECRET` | Нет | Секрет Mini App |
| `TELEGRAM_BOT_TOKEN` | Нет | Токен Telegram-бота |
| `API_KEY` | Нет | Ключ для публичного API |
| `DATABASE_URL` | Нет | URL БД (по умолч. SQLite) |

## Деплой (systemd)

```bash
sudo cp vkadmin.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable vkadmin
sudo systemctl start vkadmin
```

## Технологии

- **Python 3.12** + FastAPI + uvicorn
- **SQLAlchemy 2.0** (async) + SQLite (путь PostgreSQL из docker-compose не проверялся и, по аудиту 09.2026, несовместим: DateTime без часового пояса)
- **vkbottle** — VK API
- **OpenAI SDK** — совместимый с OpenRouter, собственными AI
- **APScheduler** — фоновые задачи
- **httpx** — async HTTP-клиент
