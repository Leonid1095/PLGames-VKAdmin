> модерирует комментарии, считает баллы — и всё разумно, на основе реальных данных.

## 🔜 Бот-администратор — следующее

- [ ] **Личный ключ админа** — удаление комментариев, баны, закрепы и фото к постам
      (ключ сообщества VK это не пускает)
- [ ] **Картинки к постам** — групп-токен не грузит фото (VK error 27). Варианты:
      (A) прикреплять ссылку источника → превью-карточка ВК; (B) токен сообщества с правами «Фото»;
      (C) загрузка через юзер-токен админа
- [ ] **Статьи без источника не выдумывать** — ветка `write_article` без URL сейчас галлюцинирует;
      блокировать или строго заземлять на описании группы
- [ ] **Модерация в дайджесте** — сводка нарушений за день (уведомления по каждому уже есть)
- [ ] **Многошаговый агент** — followup без `tools=`, нельзя сцеплять действия
      («посмотри статистику → запостить про лучшее»)
- [ ] **База знаний / FAQ группы** — факты (правила, расписание) для ответов в ЛС и комментах
- [ ] Ротация секретов: `GITHUB_TOKEN (ghp_)`, `VK_APP_SECRET`, VK-токен
